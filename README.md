**Midnight Vault** — a one-room heist game. Slip into a moonlit gallery, read the patrols' vision cones, time the sweeping security cameras, crack the vault for the Starlight Diamond, and get out through the green exit before the alarm hits 100%. Three routes cross the room, three tools cost something (noisemakers lure guards, EMP freezes a camera, the lockpick costs seconds standing still), and getting caught is fair: the alarm climbs while you are seen and bleeds away while you hide.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. No build step, no network requests — the game is static files under `game/`, and all sounds are synthesized with WebAudio.

**Controls:** WASD / arrows to move · Shift to sneak · E to crack the vault and grab loot · Click to throw a noisemaker · Q to EMP the nearest camera · R to restart · M to mute.
